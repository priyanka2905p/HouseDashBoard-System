

🏠 House Dashboard System

📌 Description
A frontend web application that simulates a smart home dashboard where users can toggle appliance switches and view real-time power consumption (in watts).

🚀 Features
Toggle switches for appliances (fan, light, etc.)
Real-time watt calculation
Dynamic UI updates using JavaScript
🛠️ Tech Stack
HTML
CSS
JavaScript

⚙️ How It Works
Each appliance has a fixed watt value. When a switch is turned ON, its watt is added to the total; when turned OFF, it is subtracted. The total updates instantly.

▶️ Run the Project
Download or clone the project
Open index.html in any browser
